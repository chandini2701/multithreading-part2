01
BACKGROUND EXECUTION

Daemon Thread

A daemon thread is a background service thread that supports other threads. The JVM can exit when no live non-daemon threads remain.

Important points

  • Use setDaemon(true) before starting the thread.
  • Use isDaemon() to check whether it is a daemon.
  • Daemon threads do not keep the JVM alive by themselves.
  • The JVM does not guarantee that daemon work will finish before exit.

03
THREAD SAFETY

Synchronization

Synchronization controls access to shared resources. A synchronized Java method allows only one thread at a time to execute it on the same object.

CONCURRENT DATA ACCESS

Race Condition

A race condition occurs when the result depends on the timing of concurrent operations on shared data without adequate coordination.
